Tema 1.4

Caso práctico

Limpieza y preparación de un conjunto de ventas con Python (Pandas + NumPy).

El problema

El archivo ventas_raw.csv está en el mismo repositorio que estas páginas HTML. Tiene faltantes, nombres de región inconsistentes, outliers, duplicados y fechas en varios formatos. El objetivo es un dataset limpio listo para análisis.

Descargar ventas_raw.csv

223 filas · mismo directorio que caso-practico.html en GitHub.

1. Carga y exploración

import pandas as pd
df = pd.read_csv("ventas_raw.csv", encoding="utf-8")
print(df.shape, df.dtypes, df.head())
print(df.isnull().sum(), df.duplicated().sum())

2. Duplicados e inconsistencias

df = df.drop_duplicates()
df["region"] = df["region"].str.strip().str.title()
mapa = {"Nte": "Norte", "S": "Sur", "Ctro": "Centro"}
df["region"] = df["region"].replace(mapa)
df["fecha"] = pd.to_datetime(df["fecha"], errors="coerce", dayfirst=True)

3. Valores faltantes

df = df.dropna(subset=["fecha", "id_producto"])
df["precio"] = df.groupby("categoria")["precio"].transform(
    lambda x: x.fillna(x.median())
)
df["cantidad"] = df["cantidad"].fillna(df["cantidad"].median())
df["region"] = df["region"].fillna("Desconocida")

4. Outliers y variables nuevas

df["precio"] = df["precio"].clip(
    lower=df["precio"].quantile(0.01),
    upper=df["precio"].quantile(0.99),
)
df["ingreso"] = df["precio"] * df["cantidad"]
df["anio"] = df["fecha"].dt.year
df["mes"] = df["fecha"].dt.month
df.to_csv("ventas_limpias.csv", index=False)

Resultado: un archivo analítico y, si se necesita modelado, otro con variables escaladas y categóricas codificadas.
