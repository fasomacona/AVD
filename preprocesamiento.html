1.3 Preprocesamiento de Datos

El conjunto de técnicas que transforman datos crudos en datos listos para el análisis.

¿Por qué es crítico el preprocesamiento?

Los datos del mundo real casi nunca están listos para ser analizados. Contienen valores faltantes, errores de captura, formatos inconsistentes, escalas diferentes, outliers y ruido. El preprocesamiento es el proceso sistemático de limpiar, transformar e integrar los datos para maximizar su utilidad y minimizar sesgos.

Regla de oro: “Garbage in, garbage out”. Un modelo sofisticado alimentado con datos mal preparados producirá resultados pobres o engañosos.

Los subtemas principales son:

  1. Muestreo y cuantificación
  2. Tipos de error y su manejo
  3. Filtrado
  4. Transformación de datos
  5. Integración de datos

1.3.1 Muestreo y Cuantificación

Muestreo

Cuando el volumen de datos es demasiado grande para procesarlo completo (o cuando se desea una estimación rápida), se utiliza el muestreo: seleccionar un subconjunto representativo.

Tipos de muestreo más usados

  • Aleatorio simple: cada observación tiene la misma probabilidad de ser seleccionada.
  • Estratificado: se divide la población en estratos (por categoría) y se muestrea proporcionalmente de cada uno. Mantiene la distribución de clases.
  • Sistemático: se selecciona cada k-ésima observación.
  • Por conglomerados (cluster): se muestrean grupos completos.
  • Muestreo temporal: en series de tiempo se toman ventanas o se reduce la frecuencia (downsampling).
# Ejemplo con Pandas: muestreo aleatorio y estratificado import pandas as pd df = pd.read_csv("datos.csv") # 10% de las filas al azar muestra_simple = df.sample(frac=0.1, random_state=42) # Muestreo estratificado por la columna 'categoria' muestra_estrat = df.groupby('categoria', group_keys=False).apply( lambda x: x.sample(frac=0.1, random_state=42) )

Cuantificación

La cuantificación (o discretización) consiste en convertir variables continuas en variables discretas o categóricas (bins). Es útil para:

  • Reducir el impacto del ruido
  • Preparar datos para algoritmos que trabajan mejor con categorías
  • Crear variables más interpretables (ej. rangos de edad, niveles de ingreso)
# Discretización en bins de igual ancho df['edad_grupo'] = pd.cut(df['edad'], bins=[0, 18, 30, 50, 100], labels=['Menor', 'Joven', 'Adulto', 'Mayor']) # Discretización en cuantiles (igual frecuencia) df['ingreso_nivel'] = pd.qcut(df['ingreso'], q=4, labels=['Bajo', 'Medio-Bajo', 'Medio-Alto', 'Alto'])

1.3.2 Tipos de Error y su Manejo

Los errores en los datos pueden clasificarse de varias formas:

Tipos principales de problemas de calidad

Tipo de problema Ejemplo Estrategia de manejo
Valores faltantes (Missing) NaN, None, celdas vacías Eliminación, imputación (media, mediana, moda, modelos), indicadores de missingness
Outliers / Anomalías Edad = 250, ingresos negativos Detección (IQR, Z-score, Isolation Forest), capado, eliminación o investigación
Inconsistencias "México", "mexico", "MEX" Estandarización, diccionarios de mapeo, fuzzy matching
Duplicados Misma fila repetida Identificación y eliminación (drop_duplicates)
Errores de formato Fechas en distintos formatos, números como texto Parsing, conversión de tipos (astype, to_datetime)
Ruido Variaciones aleatorias en sensores Suavizado, filtros, promedios móviles

Manejo de valores faltantes – técnicas principales

  • Eliminación (listwise / pairwise): simple pero puede sesgar si los missing no son aleatorios.
  • Imputación por estadísticos: media, mediana (robusta a outliers), moda.
  • Imputación por modelos: KNN, regresión, Random Forest, MICE.
  • Indicador de missing: crear una columna binaria que indique si el valor estaba faltante (útil cuando el missing es informativo).
# Manejo básico de valores faltantes con Pandas # Contar missing por columna print(df.isnull().sum()) # Eliminar filas con cualquier NaN df_clean = df.dropna() # Imputar con la mediana df['salario'] = df['salario'].fillna(df['salario'].median()) # Imputar con un valor constante df['categoria'] = df['categoria'].fillna('Desconocido')

1.3.3 Filtrado

El filtrado consiste en seleccionar un subconjunto de observaciones o variables según criterios específicos. Se usa para:

  • Eliminar registros irrelevantes o erróneos
  • Enfocarse en un segmento de interés (ej. solo clientes activos)
  • Reducir ruido o datos fuera de rango
  • Seleccionar características (feature selection)
# Filtrado de filas # Solo registros de 2023 y con ventas > 1000 filtro = (df['anio'] == 2023) & (df['ventas'] > 1000) df_filtrado = df.loc[filtro] # Filtrado de columnas columnas_utiles = ['id', 'fecha', 'producto', 'cantidad', 'precio'] df = df[columnas_utiles] # Eliminar outliers con IQR Q1 = df['precio'].quantile(0.25) Q3 = df['precio'].quantile(0.75) IQR = Q3 - Q1 df_sin_outliers = df[(df['precio'] >= Q1 - 1.5*IQR) & (df['precio'] <= Q3 + 1.5*IQR)]

1.3.4 Transformación de Datos

Las transformaciones modifican los valores de las variables para hacerlos más adecuados al análisis o a los algoritmos posteriores.

Transformaciones más frecuentes

  • Normalización / Escalado:
    • Min-Max Scaling → [0, 1]
    • Standardization (Z-score) → media 0, desviación 1
    • Robust Scaler (usa mediana e IQR)
  • Transformaciones matemáticas: log, raíz cuadrada, Box-Cox, Yeo-Johnson (para reducir sesgo y estabilizar varianza).
  • Codificación de variables categóricas:
    • One-Hot Encoding
    • Label Encoding
    • Target Encoding / Ordinal Encoding
  • Creación de variables derivadas: ratios, diferencias, agregaciones, features temporales (día de la semana, mes, lag features).
from sklearn.preprocessing import StandardScaler, MinMaxScaler, OneHotEncoder import numpy as np # Estandarización scaler = StandardScaler() df['salario_std'] = scaler.fit_transform(df[['salario']]) # Transformación logarítmica (útil para datos con sesgo positivo) df['ventas_log'] = np.log1p(df['ventas']) # log(1+x) evita log(0) # One-Hot Encoding df_encoded = pd.get_dummies(df, columns=['region', 'tipo_cliente'], drop_first=True)
Importante: Las transformaciones de escala (StandardScaler, MinMax) deben ajustarse solo con los datos de entrenamiento y luego aplicarse a los datos de prueba/validación para evitar data leakage.

1.3.5 Integración de Datos

La integración consiste en combinar datos provenientes de múltiples fuentes en una vista unificada y coherente. Es uno de los pasos más complejos del preprocesamiento.

Desafíos de la integración

  • Heterogeneidad de esquemas: diferentes nombres de columnas, tipos de datos, granularidades.
  • Conflictos de valores: la misma entidad tiene valores distintos en fuentes diferentes.
  • Duplicación de entidades: el mismo cliente aparece con IDs o nombres ligeramente distintos.
  • Diferencias temporales: datos de distintos periodos o frecuencias de actualización.

Técnicas principales

  • Joins / Merges: inner, left, right, outer joins (Pandas merge, SQL JOIN).
  • Concatenación vertical u horizontal.
  • Entity resolution / Record linkage: emparejar registros que se refieren a la misma entidad del mundo real.
  • Data lakes y data warehouses: arquitecturas que facilitan la integración a escala.
# Integración con Pandas merge clientes = pd.read_csv("clientes.csv") compras = pd.read_csv("compras.csv") # Left join: conservar todos los clientes aunque no tengan compras df_integrado = pd.merge(clientes, compras, on='id_cliente', how='left') # Concatenar datasets con la misma estructura df_total = pd.concat([df_2022, df_2023], ignore_index=True)

Flujo típico de preprocesamiento

  1. Exploración inicial (EDA): formas, tipos, missing, distribución
  2. Limpieza: manejo de missing, duplicados, inconsistencias, outliers
  3. Filtrado y selección de variables relevantes
  4. Transformación y codificación
  5. Integración de fuentes adicionales (si aplica)
  6. Validación final y exportación del dataset limpio

Este flujo no es estrictamente lineal: muchas veces se itera entre exploración, limpieza y transformación a medida que se descubren nuevos problemas.
