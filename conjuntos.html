Tema 1.1

Conjunto de datos

Las tres características que definen los datos actuales: volumen, variedad y velocidad.

Qué es un conjunto de datos

Un dataset es una colección —estructurada o no— de observaciones sobre un fenómeno. Puede ser una tabla, documentos, imágenes, series o grafos. En ciencia de datos moderna se describe con las 3 Vs del Big Data.

Volumen

Cantidad masiva generada y almacenada.

Variedad

Formatos, tipos y fuentes diversos.

Velocidad

Ritmo al que llegan y deben procesarse.

1.1.1 Alto volumen

Terabytes a exabytes. Ejemplos: redes sociales, IoT industrial, comercio electrónico, genómica. Cargar todo en RAM deja de ser viable: se usa almacenamiento distribuido, procesamiento paralelo y muestreo inteligente.

DesafíoMitigación
AlmacenamientoHDFS, object storage, compresión
CómputoParalelo, Spark, MapReduce
CalidadMás datos no implica mejores datos

1.1.2 Alta variedad

Estructurados

SQL, hojas de cálculo, CSV

Semi-estructurados

JSON, XML, logs, correo

No estructurados

Texto, imagen, video, audio

Ejemplo. Un recomendador combina compras (tabla), clics (JSON) y reseñas (texto libre).

1.1.3 Alta velocidad

  • Batch: periódico (reportes diarios o mensuales).
  • Near real-time: segundos o minutos (inventario).
  • Streaming: continuo (fraude, sensores, semáforos).

Tecnologías típicas: Kafka, Flink, Spark Streaming, Redis, arquitecturas Lambda/Kappa y edge computing.
