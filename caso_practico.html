1.4 Caso Práctico

Limpieza y preparación completa de un conjunto de datos de ventas con Python (Pandas + NumPy).

Descripción del caso

Una empresa de retail desea analizar las ventas de sus tiendas. El archivo ventas_raw.csv contiene datos de transacciones, pero presenta múltiples problemas de calidad típicos del mundo real:

  • Valores faltantes en varias columnas
  • Inconsistencias en nombres de regiones y categorías
  • Valores atípicos (outliers) en precios y cantidades
  • Duplicados
  • Formatos de fecha inconsistentes
  • Columnas con tipos de datos incorrectos

El objetivo es producir un dataset limpio, consistente y listo para análisis y visualización posteriores.

Paso 1: Carga y exploración inicial

import pandas as pd import numpy as np import matplotlib.pyplot as plt import seaborn as sns # Cargar el dataset df = pd.read_csv("ventas_raw.csv", encoding="utf-8") # Vista general print("Dimensiones:", df.shape) print("\nTipos de datos:\n", df.dtypes) print("\nPrimeras filas:\n", df.head()) print("\nResumen estadístico:\n", df.describe(include='all')) print("\nValores faltantes:\n", df.isnull().sum()) print("\nDuplicados:", df.duplicated().sum())
Qué observar: número de filas y columnas, tipos de datos inesperados (ej. precios como object), porcentaje de missing por columna, presencia de duplicados.

Paso 2: Limpieza de duplicados e inconsistencias básicas

# Eliminar duplicados exactos df = df.drop_duplicates() # Estandarizar texto (minúsculas y strip) df['region'] = df['region'].str.strip().str.title() df['categoria'] = df['categoria'].str.strip().str.title() # Mapear valores inconsistentes mapa_regiones = { 'Norte': 'Norte', 'Nte': 'Norte', 'norte': 'Norte', 'Sur': 'Sur', 'S': 'Sur', 'Centro': 'Centro', 'Ctro': 'Centro' } df['region'] = df['region'].replace(mapa_regiones) # Convertir fechas df['fecha'] = pd.to_datetime(df['fecha'], errors='coerce', dayfirst=True)

Paso 3: Manejo de valores faltantes

# Estrategia diferenciada según la columna # 1. Si la fecha es crítica y está faltante → eliminar la fila df = df.dropna(subset=['fecha', 'id_producto']) # 2. Precio: imputar con la mediana por categoría df['precio'] = df.groupby('categoria')['precio'].transform( lambda x: x.fillna(x.median()) ) # 3. Cantidad: imputar con la mediana global df['cantidad'] = df['cantidad'].fillna(df['cantidad'].median()) # 4. Región: crear categoría "Desconocida" df['region'] = df['region'].fillna('Desconocida') # Verificar que ya no haya missing críticos print(df.isnull().sum())

Paso 4: Detección y tratamiento de outliers

# Función para detectar outliers con método IQR def detectar_outliers_iqr(serie): Q1 = serie.quantile(0.25) Q3 = serie.quantile(0.75) IQR = Q3 - Q1 limite_inf = Q1 - 1.5 * IQR limite_sup = Q3 + 1.5 * IQR return (serie < limite_inf) | (serie > limite_sup) # Identificar outliers en precio y cantidad outliers_precio = detectar_outliers_iqr(df['precio']) outliers_cantidad = detectar_outliers_iqr(df['cantidad']) print(f"Outliers en precio: {outliers_precio.sum()}") print(f"Outliers en cantidad: {outliers_cantidad.sum()}") # Opción 1: Eliminar outliers extremos # df = df[~outliers_precio & ~outliers_cantidad] # Opción 2 (recomendada en muchos casos): Capado (winsorizing) df['precio'] = df['precio'].clip( lower=df['precio'].quantile(0.01), upper=df['precio'].quantile(0.99) ) df['cantidad'] = df['cantidad'].clip(lower=1, upper=df['cantidad'].quantile(0.99))

Paso 5: Transformaciones y creación de variables

# Crear variable de ingreso total df['ingreso'] = df['precio'] * df['cantidad'] # Extraer componentes de fecha df['anio'] = df['fecha'].dt.year df['mes'] = df['fecha'].dt.month df['dia_semana'] = df['fecha'].dt.day_name() df['trimestre'] = df['fecha'].dt.quarter # Codificación de variables categóricas (ejemplo One-Hot) df_encoded = pd.get_dummies(df, columns=['region', 'categoria'], prefix=['reg', 'cat'], drop_first=True) # Escalado de variables numéricas (para modelos posteriores) from sklearn.preprocessing import StandardScaler scaler = StandardScaler() cols_num = ['precio', 'cantidad', 'ingreso'] df_encoded[cols_num] = scaler.fit_transform(df_encoded[cols_num])

Paso 6: Validación final y exportación

# Chequeos finales print("Dimensiones finales:", df.shape) print("\nValores faltantes restantes:\n", df.isnull().sum()) print("\nTipos de datos:\n", df.dtypes) print("\nResumen de ingreso:\n", df['ingreso'].describe()) # Guardar el dataset limpio df.to_csv("ventas_limpias.csv", index=False, encoding="utf-8") df_encoded.to_csv("ventas_modelado.csv", index=False, encoding="utf-8") print("\n✓ Datasets exportados correctamente")
Resultado esperado: Un archivo ventas_limpias.csv listo para análisis exploratorio y visualización, y un archivo ventas_modelado.csv con variables numéricas escaladas y categóricas codificadas, preparado para algoritmos de machine learning.

Buenas prácticas aplicadas en este caso

  • Exploración antes de cualquier modificación (nunca limpiar a ciegas).
  • Decisiones de imputación justificadas por el contexto del negocio.
  • Tratamiento de outliers con métodos robustos (IQR + capado).
  • Creación de variables derivadas útiles para el análisis.
  • Separación clara entre dataset “analítico” y dataset “para modelado”.
  • Documentación del proceso (el código en sí es la documentación reproducible).
